# PaperLens Studio

PaperLens Studio 是一个本地优先的论文阅读、带读、批注和文献整理工作台。

## 功能

### 导师带读风格

单篇论文分析现在会用更自然的导师式语言：先用白话解释，再说明学术含义；解释作者为什么这样安排；区分原文明确内容、结构推断和阅读建议；对“较难”部分要求提供白话解释、论文例子或类比，以及该概念对全文论证的作用。提示词会避免重复“本节主要讨论”“作者通过”“读者需要注意”等机械句式。


- 七步新手引导：上传、开始带读、阅读原文、查看结果、文献组对比、文件夹分类、更多工具。完成或跳过后不再自动出现，可通过顶部“更多 → 使用引导”重看。
- 单篇论文主流程：上传 PDF 后，直接点击上传区下方的“开始带读分析”；可选研究主题和分析开关在“带读选项”中。
- 多篇文献对比：展开左侧“带读选项”下方的“多篇文献对比”，选择 2–8 篇 PDF；结果显示在右侧“更多结果 → 文献综述”。
- PDF 缩放：点击阅读区的＋/−会即时改变页面大小，并保持当前阅读位置；不会重新加载整篇论文。
- 右侧阅读结果：带读按章节解释，论证链串起全文问题、主张、论据和写法；核验将页码、引文检查与原文候选句合在一处。文字相近不代表论点已被证实，仍需人工判断。
- 右栏字号：A− / A＋ 现位于“阅读结果”标题旁；标题栏在右侧内容滚动时保持可见，桌面和窄屏抽屉都可随时调节。右栏宽度仍在顶部“更多”菜单中。
- 原刊页码与 PDF 页序：如果模型把原刊第 55 页误当成 PDF 第 55 页，工作台会优先用可唯一定位的原文引文换算页码；引文不足时仅对连续且整体越界的页码作推定，并明确提示。页码按钮始终表示 PDF 页序；证据不足的孤立越界页码会标为“未定位”，不会假装可点击。旧版本地带读报告打开时也会重新核对。
- 阅读状态：最近论文同时显示文字与圆点。橙色“已上传”、蓝绿色“已生成报告”由工作台自动判断；绿色“已读”只能通过当前论文的“标为已读”或最近论文右键菜单手动设置，也可撤销。未生成报告也能标已读，此时显示“已读 · 待带读”。
- 快速抓重点：在“更多结果 → 思维导图”上方增加三条单行提示（主张、可借鉴、核对）；只复用已有报告，不额外调用 AI，较长文字可悬停查看完整内容。
- 与已读论文对照：在单篇“带读”里展开入口，手动勾选最多 8 篇已读且有报告的论文；发送前可预览当前与所选报告摘要，并须单独确认。不会发送 PDF 全文，也不会自动读取未选论文。结果分“此前已见／相近但有差异／在已读库中未见”，附所选来源论文；“未见”只相对于这次选定的已读报告，不代表学术首创。结果保存在本地，来源取消已读或报告更新后会失效。
- 重复上传与分析缓存：上传 PDF 时按文件内容的 SHA-256 校验；相同文件即使改名也会打开已有记录，保留其报告、批注、已读状态和文件夹。旧版已经存在的重复记录不会被自动删除或合并。文件名、大小相同而内容不同的 PDF 会分别保存。文献组分析缓存仅在 PDF 内容、研究主题、接口、模型和分块参数一致时复用；旧版“文件名＋大小”缓存不再读取。
- 来源追溯与返回：跨论文提示中的来源论文名称可以点击；有页码时跳到来源 PDF 页，无页码时明确标为“页码待核对”。阅读区的“返回原论文”会回到跳转前的论文、阅读位置和结果面板。跳转和返回不会自动调用 AI。
- 阅读位置：翻页或滚动后自动保存当前 PDF 页及页内位置；再次从最近论文打开时恢复。阅读位置不等于“已读”，不会自行修改已读标记。
- 写作素材收藏：在“论证链”的论据与写作动作旁点“☆ 收藏”，可在“批注 → 我的写作素材”查看所有论文的已收藏观点与写法、回到来源 PDF 或移除。收藏的是报告中的表述，仍需回原文核对；不额外调用 AI。素材与阅读位置均包含在工作台备份中。
- 本轮沿用既有 AI 分析格式：论据和写作动作可按页码回跳；研究问题与核心主张尚无独立的精确原文定位，页面会明确提示这一点。
- 窄屏查看结果：点击 PDF 工具栏的“阅读结果”打开侧栏，点击页码引用会返回原文。

- PDF.js 解析与渲染
- 扫描 PDF OCR
- 分块论文带读
- 论点、方法、证据和页码核验
- 在“核验”中逐条展开 AI 判断与原文候选句对照
- 多篇论文比较与研究空白提炼
- 论文文件夹管理

## 启动

需要 Node.js 18+。双击：

```
启动 PaperLens.bat
```

它会启动本地服务器并自动打开浏览器。黑色命令窗口是后台服务，使用期间不要关闭。

也可以手动运行：

```powershell
node .\paperlens-server.mjs
```

然后访问 http://127.0.0.1:5173。

## 自检

修改后可运行：

```powershell
node .\check-engine.mjs
node .\check-page-mapping.mjs
node .\check-read-memory.mjs
node .\check-tour.mjs
node .\check-layout.mjs
node .\check-ui.mjs
```

引擎自检检查不完整/旧版分析数据的兼容性；引导、布局与 UI 自检检查关键入口、研究主题空值、窄屏结果和脚本语法。

## AI 接口

在页面右上角“更多 → AI 接口设置”中配置 OpenAI 兼容接口。API Key 只保存在当前浏览器会话中。公开部署时不要把长期密钥写入前端，建议使用后端代理。

## 新手引导

首次打开新版网页会显示七步引导，可点“跳过引导”。之后可通过“更多 → 使用引导”重新查看。是否看过引导只保存在当前浏览器的 localStorage。

## 隐私说明

- 项目不包含任何真实论文、作者姓名或个人研究主题。
- 可通过“更多 → 备份工作台数据”备份论文 PDF、分析、批注和文件夹；升级版本后可通过“导入工作台数据”恢复。
- “更多”中的带读报告导出保留标题、颜色、背景和章节排版。
- “导出批注版”会生成真正的 PDF：保留原页面，在原文对应位置叠加半透明高亮，并在每页右侧新增空白批注栏；有文字备注的批注卡片与高亮位置以连线关联。只有高亮、没有备注的标记只叠加在原文上，不会生成空的侧栏卡片。批注卡片使用统一字号并按内容自动换行、扩展高度；中文批注会渲染为图像嵌入，以减少字体缺失问题。原始 PDF 不会被覆盖。
- PDF 批注导出使用 CDN 加载 pdf-lib，但只在点击“导出批注版”时加载，不拖慢页面首次打开。中文页边标题和批注以 PNG 图像嵌入，避免 WinAnsi 字体编码错误；导出时仍需联网加载 pdf-lib。
- 论文、分析、批注和文件夹默认保存在本机浏览器 IndexedDB。
- 使用 AI 分析时，论文文字会发送到你配置的模型服务，请根据材料敏感程度选择接口。
- 本项目不提供任何内置私人示例。
